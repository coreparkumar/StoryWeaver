What You Need to Generate accountAssociation
Your Farcaster private key (Ed25519 key) associated with your FID 977521.
This key signs the JWT-like structure to prove ownership of your mini app domain.

Node.js (or another environment where you can run Ed25519 signing code)

Structure of the accountAssociation Fields
header — JSON, typically:

json
{ "alg": "ed25519", "typ": "JWT" }
base64url-encoded (no padding)

payload — JSON containing your FID and domain, e.g.:

json
{
  "fid": 977521,
  "domain": "story-chain-paaritoshkumar.replit.app"
}
base64url-encoded (no padding)

signature — Ed25519 signature of the string: header_base64url + "." + payload_base64url

Step-by-Step Example Using Node.js
Install dependencies:

bash
npm install tweetnacl base64url
Script to generate the accountAssociation:

js
const nacl = require('tweetnacl');
const base64url = require('base64url');

// Replace with your own Ed25519 private key as a 32-byte hex string or Uint8Array
// For demo purposes, this is a random key. You must use your actual key.
const privateKeyHex = 'YOUR_PRIVATE_KEY_IN_HEX'; 

// Convert hex private key string to Uint8Array
const privateKey = Uint8Array.from(Buffer.from(privateKeyHex, 'hex'));

// Header JSON
const header = {
  alg: 'ed25519',
  typ: 'JWT'
};

// Payload JSON
const payload = {
  fid: 977521,
  domain: 'story-chain-paaritoshkumar.replit.app'
};

// Encode header and payload with base64url (no padding)
const encodedHeader = base64url.encode(JSON.stringify(header));
const encodedPayload = base64url.encode(JSON.stringify(payload));

// Prepare signing input
const message = `${encodedHeader}.${encodedPayload}`;

// Sign the message using the private key
// tweetnacl expects a 64-byte secret key: 32 bytes private key + 32 bytes public key
// If you only have 32 bytes private, you must generate the full keypair
const keypair = nacl.sign.keyPair.fromSeed(privateKey);
// keypair.secretKey is the 64-byte full secret key

const signatureUint8 = nacl.sign.detached(Buffer.from(message), keypair.secretKey);
const signature = base64url.encode(signatureUint8);

console.log('header:', encodedHeader);
console.log('payload:', encodedPayload);
console.log('signature:', signature);
Notes:
The privateKeyHex must be your actual Ed25519 seed (32 bytes) or the key you use for your Farcaster identity for FID 977521.

If your private key is stored in another format, you will need to convert it to a 32-byte seed.

The standard Ed25519 secret key used by tweetnacl is 64 bytes: 32-byte seed + 32-byte public key. The above script generates the full key pair from the private seed.

If you don’t have your key, or are unsure where to get it, typically it comes from your wallet or Farcaster account signer.
