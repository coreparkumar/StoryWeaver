Build "Story Weaver" Farcaster Mini App
Objective:
Build a Farcaster Mini App, "Story Weaver," where users can collaboratively write a story by liking a post and then adding their story part as a comment. Only users who like the post can comment. The post creator can read submissions and choose to share the post to any commenter—when that happens, the commenter’s submission is appended to the original post and shared back to them, creating a collaborative story loop.

Technical Prerequisites
Node.js (v22.11.0+)

React (or Next.js)

Farcaster Mini App SDK

Manifest must associate with FID 977521 (acting as the verified app owner/account)

Requirements & Workflow
User Authentication:

Authenticate users via Farcaster Mini App SDK.

Story Post UI:

Display the current story (one post by the creator/FID 977521).

For each post, display a "Like" button and a comment section.

Permission Control:

Only users who have liked the post may add a comment.

Each comment is a proposed story continuation.

Collaboration Workflow:

The post creator (creator FID=977521) sees all user-submitted comments.

The creator may select any comment to accept and "share" into the main story.

Upon sharing, the selected story part is appended to the original post and also sent/shared to the commenter.

Store all data (posts, likes, comments, merges) in a free database backend (start with Replit Database for local development; consider Supabase, Firebase, or MongoDB Atlas for scaling).

Manifest Setup:

/public/.well-known/farcaster.json must include:

"name": "Story Weaver"

Link domain association to FID 977521 per mini app specification.

"homeUrl" set to your Replit public URL.

Other required fields (icon, description).

Manifest (/public/.well-known/farcaster.json) Example
json
{
  "accountAssociation": {
    "header": "<base64-encoded-header-with-fid-977521>",
    "payload": "<base64-encoded-payload-with-your-replit-domain>",
    "signature": "<signature-associating-fid-977521-with-domain>"
  },
  "miniapp": {
    "version": "1",
    "name": "Story Weaver",
    "homeUrl": "https://<your-replit-url>",
    "iconUrl": "https://<your-replit-url>/icon.png",
    "description": "Collaboratively write a story—like and comment to add your twist!"
  }
}
(Generate header, payload, and signature according to Farcaster Mini App documentation—see the "accountAssociation" details in the official spec.)

Development Steps
Scaffold app in Replit (Node.js + React).

Install @farcaster/miniapp-sdk.

Implement like/comment logic gating (only commenters who have liked may post; verify via SDK).

Build creator dashboard to read comments and use a button (e.g., "Add & Share") to merge/append commenter’s text into the main post and send it back to the selected commenter (using share/embed guides for Farcaster Mini Apps).

Store and fetch likes/comments/story in your database layer.

Set “homeUrl” in your manifest to your public Replit URL for instant preview/testing.

Make sharing robust—use embed meta tags for shareable links per mini app sharing best practices.

Tips
Start with the Monad mini app template for quick setup.

Use SDK sdk.actions.getUser() to retrieve FID and validate current user actions.

Implement sharing using Farcaster embed meta tags for viral story spread.

Paste this prompt directly into Replit’s AI or your setup instructions.
You can further adapt app logic to add moderation, versioning, or richer collaboration features as you scale!
