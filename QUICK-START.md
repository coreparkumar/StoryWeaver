# Story Weaver - Quick Farcaster Deploy

## 📱 Immediate Steps (5 minutes)

### 1. Deploy Now
Click the **Deploy** button above → Get your `.replit.app` URL

### 2. Update Your Domain (30 seconds)
```bash
# Run this script with your deployed URL
chmod +x farcaster-deploy-script.sh
./farcaster-deploy-script.sh
```

### 3. Generate Farcaster Signature
**Option A - Warpcast App (Easiest):**
1. Open Warpcast on phone
2. Settings → Advanced → Developer Settings
3. "Sign Account Association" 
4. Enter your domain: `yourapp.replit.app`
5. Copy signature to `client/public/.well-known/farcaster.json`

### 4. Test Your Setup
Visit: `https://yourapp.replit.app/.well-known/farcaster.json`
Should show valid JSON with your FID (977521)

### 5. Go Live on Farcaster
Create your first cast:
```
🧙‍♂️ NEW: Story Weaver - Collaborative storytelling!

How it works:
✨ Like → Write → Build stories together
📝 280 chars per contribution  
🔒 No editing conflicts

Join the story: https://yourapp.replit.app

#Farcaster #Stories #MiniApp
```
